项目：GPU Steward
当前阶段：v0.1 MVP 已发布到 GitHub public main
正在推进：稳定性观察与真实 Codex/SSH 工作流试用
下一步：根据试用决定是否加入持久 daemon、多用户 ACL、priority aging 和多主机调度
关键约束：
- 单服务器、单 Unix 用户、NVIDIA 整卡独占为 v1 范围
- GPU 数量必须动态查询，不硬编码 4
- 外部计算进程占用的 GPU fail closed，绝不终止未知进程
- 空闲 4 卡时首任务 3 卡、第二任务 1 卡；释放批次按等待任务公平分配
- 已启动任务不动态改变 GPU 数量
- Python 3.8+，优先标准库，无 root/容器/Slurm 依赖
